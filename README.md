# PetLume

Plataforma web de adoção responsável que aproxima pessoas interessadas em adotar de doadores de pets. O MVP permite criar contas, publicar e buscar anúncios e acompanhar solicitações de adoção.

**Tecnologias:** React e Vite no front-end; Python, FastAPI e SQLAlchemy no back-end; PostgreSQL como banco de dados.

## O que já funciona

- Cadastro e login de adotantes e doadores.
- Publicação e busca de anúncios por espécie, porte e cidade.
- Solicitação de adoção e acompanhamento do status.
- Aprovação ou recusa pelo doador.
